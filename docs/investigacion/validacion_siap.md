# Validación contra rendimientos de SIAP (RD-003)

Rendimiento simulado promedio 2015-2024 debe quedar dentro de ±40 % del promedio SIAP del mismo municipio y periodo.
Criterio de aceptación: al menos 4 de 5 municipios dentro de ±40 % para maíz.
